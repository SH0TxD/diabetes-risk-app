# DiaRisk Bosnia - Type 2 Diabetes Risk Awareness Prototype

A Streamlit prototype for Challenge 1: Understanding Personal Health Risks.

## What it does
- Collects personal, family, lifestyle, and optional lab information
- Calculates an explainable type 2 diabetes risk category
- Provides safe, non-diagnostic next steps
- Tracks health parameters over time
- Includes a doctor-map placeholder for future integration

## Important medical disclaimer
This is not a diagnostic tool and does not prescribe treatment. It is a preventive support prototype that encourages users to consult a licensed medical professional.

## How to run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Suggested demo flow
1. Open the Risk Assessment page.
2. Enter user information.
3. Show the risk category and explanations.
4. Open AI Advice to show personalized but safe recommendations.
5. Open Health Tracking to log a sample glucose or HbA1c value.
6. Open Find Doctors to show future specialist-navigation support.
